# 六年級第一次考試詞語遊戲

此套件包含32題、四個故事場景、平板版面和錯題重溫。答錯只給提示，答對才能繼續。

GitHub Pages 發布：
1. 解壓縮 ZIP。
2. 在 GitHub 新建 Public 儲存庫，例如 p6-word-adventure，建立時勾選 Add a README file。
3. 選 Add file > Upload files，上載 index.html、style.css、data.js、app.js 至儲存庫最上層，然後 Commit changes。請勿只上載 ZIP 或把整個外層資料夾上載。
4. 進入 Settings > Pages。Source 選 Deploy from a branch；Branch 選 main；Folder 選 /(root)；按 Save。
5. 等待發布完成，從 Pages 頁面複製網站網址。
6. 先用學校平板及 Wi-Fi 測試網址、中文輸入和答題，再把網址放上班級平台或製作 QR Code。

學生只需要開啟發布後的網站網址，不需 GitHub 或 ChatGPT 帳戶。不要分享 GitHub 儲存庫頁面代替遊戲網址。
遊戲不連接 ChatGPT 或 AI API。是否能在學校網絡開啟須實測。
作答進度儲存在各裝置的瀏覽器，沒有自動上傳教師成績表；共用平板換學生時可按「重新開始」。

更新時，用新版同名檔案覆蓋原檔並 Commit changes 即可。
